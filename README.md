# 🗄️ Estudos de Banco de Dados — DSM

Repositório dedicado aos meus estudos e práticas acadêmicas em **Banco de Dados**, desenvolvidos durante o curso de **Desenvolvimento de Software Multiplataforma (DSM) — Fatec**.

## 🎯 Objetivo

Consolidar conhecimentos sobre modelagem, estruturação e manipulação de bancos de dados relacionais, por meio de exercícios, atividades e projetos práticos.

## 💻 Tecnologias e ferramentas

- **MySQL** — Sistema de gerenciamento de banco de dados relacional.
- **SQL** — Linguagem para consulta e manipulação de dados.
- **MySQL Workbench** — Ferramenta para modelagem e administração de bancos de dados.

## 📚 Conteúdos estudados

- Fundamentos de Banco de Dados.
- Modelagem de dados.
- Modelo Entidade-Relacionamento (MER).
- Diagrama Entidade-Relacionamento (DER).
- Criação e estruturação de tabelas.
- Tipos de dados e restrições.
- Chaves primárias (PRIMARY KEY).
- Chaves estrangeiras (FOREIGN KEY).
- Relacionamentos entre tabelas.
- Comandos SQL (DDL e DML).
- Consultas e manipulação de dados.
- Normalização de banco de dados.

## 📂 Organização do repositório

Os arquivos estão organizados de acordo com as atividades, exercícios e conteúdos desenvolvidos ao longo da disciplina.

## 🚀 Desenvolvimento

Este repositório acompanha minha jornada de aprendizado em Banco de Dados, reunindo conhecimentos teóricos e aplicações práticas, desde os conceitos fundamentais até a construção de estruturas relacionais utilizando SQL e MySQL.
